# Curso Online sobre Indisciplina Escolar para professores

Platform: ProfessorIdeal
Source: https://www.professorideal.com/curso-online/
Source type: professorideal_page_snippet

Curso online para você aprender estratégias e atividades transformadoras para prevenir e trabalhar indisciplina escolar. A promessa é deixar o semestre menos estressante e mais produtivo, com alunos mais comportados, respeitosos, motivados e participativos.
