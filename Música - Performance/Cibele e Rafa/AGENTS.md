## Rules
- Never overwrite user edits unless the user explicitly asks for it.
- Do not invent biographical facts. If a fact is not confirmed, mark it as `a confirmar`.
- If you do web research, log the useful findings in `identidade/pesquisa_publica.md` with links.
- Use ASCII filenames and date-stamp generated outputs, for example `outputs/2026-04-16/`.
- Keep generated assets separate from source notes.
- When editing repertoire, preserve notes about tone, use case and medleys.
- When editing content, always record source clip, song, cut points, status and caption.
- When asked for a setlist, optimize for event type, duration, audience energy, vocal comfort and must-play or avoid songs.
- When asked for captions, follow `conteudo/legendas.md` and keep the voice human, direct and musical.
- If a directory has no media yet, do not pretend there is; leave the structure ready for the next drop.
