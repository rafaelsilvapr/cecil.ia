# Videos

Este folder deve organizar o material bruto e os recortes prontos para publicacao.

## Estrutura Sugerida
- `bruto/`
- `selecionados/`
- `legendados/`
- `prontos/`
- `publicados/`

## Registro Minimo
- arquivo de origem
- data
- musica ou bloco
- trecho
- duracao
- status
- legenda
- canal de publicacao

Nao ha videos locais neste snapshot, fora os previews gerados da planilha. Quando novos arquivos chegarem, separar o bruto do recorte aprovado.
