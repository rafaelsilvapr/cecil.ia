# Arte Final

Este folder deve guardar as pecas visuais aprovadas para uso final.

## Tipos De Arquivo
- thumb
- capa
- card
- banner
- arte de post

## Registro Minimo
- origem
- formato
- uso
- status
- direitos
- observacoes

## Regra
Se a arte nao foi aprovada, ela nao deve ficar misturada com a arte final.
