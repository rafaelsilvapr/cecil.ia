# Indisciplina y violencia escolar

Source: google_books_meta

Esta obra se divide en tres partes. La primera describe las variables de la indisciplina y violencia educacionales, proponiendo casos y un cuestionario para definir las situaciones, pasando luego a proporcionar un estudio sistemático de las causas. La segunda parte consiste en un estudio de un caso concreto en un IES, poniendo en conjunción cada uno de los recursos y ofreciendo propuestas para mejorar las situaciones con problemas de convivencia escolar. La parte final está compuesta por un conjunto de anexos que concretan cuestionarios, procedimientos, para abordar las indisciplinas, violencias, etc., así como una amplia bibliografía.
