# Aula nota 10: 49 técnicas para se tornar um professor campeão de audiência

Source: google_books_meta

É possível melhorar o nível de aprendizado dos alunos e sua relação com as matérias? Doug Lemov, professor, diretor de escolas e pesquisador do aprendizado tem certeza que sim. Mas não é só isso, para ele criar as 49 técnicas capazes de dar aos alunos uma vida estudantil mais efetiva, só faria sentido se fosse a partir dos melhores professores. Eles foram identificados, gravados e acompanhados de perto, especialistas em sistema cognitivo entraram em campo e o autor foi nomeando e definindo como as tais técnicas operam. O resultado é um plano de ação para os mais diversos momentos de uma dinâmica de aula, um verdadeiro aliado de professores dedicados e que querem ter uma ação mais eficaz sobre o a vida dos alunos. Desde o lançamento o livro é uma verdadeira revolução nas práticas de sala de aula. Essa é uma revolução que o Brasil precisa.
