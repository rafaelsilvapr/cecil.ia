# Templates da base de dicas

Use estes modelos como ponto de partida para capturar, classificar e maturar ideias.

## Ordem de uso

1. Capturar a ideia como `dica`.
2. Agrupar dicas parecidas em `bloco_em_construcao`.
3. Promover a ideia para `protocolo_candidato` quando houver dor clara, mecanismo e sustentacao.
4. Registrar a evidencia em `caixa_tecnica` ou em `referencia`.

## Arquivos

- `template_dica.md`
- `template_bloco_em_construcao.md`
- `template_protocolo_candidato.md`
- `template_caixa_tecnica.md`
- `template_referencia.md`
