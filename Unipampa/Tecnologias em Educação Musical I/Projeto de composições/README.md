# Projeto de composicoes

Pasta exclusiva para o trabalho de composicao com os alunos em sala.

## Arquivos principais

- `AGENTS.md`: fonte de verdade do projeto (regras e direcao base).
- `PROJETO_MASTER.md`: visao geral, objetivos, entregaveis, decisoes e pendencias.
- `AULAS_DO_PROJETO.md`: chamada do grupo do projeto + diario detalhado de cada encontro.
- `FERRAMENTAS.md`: apps, sites e materiais utilizados/testados.
- `Evidencias/`: fotos e anexos.
- `producao/`: pipeline por etapas de execucao.
- `producao/02_rascunhos/`: ideias iniciais e textos em exploracao.

## Uso rapido apos cada encontro

1. Atualizar `AULAS_DO_PROJETO.md` (presenca + narrativa completa).
2. Registrar mudancas de escopo em `PROJETO_MASTER.md`.
3. Adicionar novos recursos em `FERRAMENTAS.md`.
4. Guardar foto/anexo em `Evidencias/`.
5. Registrar rascunhos de composicao em `producao/02_rascunhos/` quando houver ideias em teste.
