# Identidade

This folder defines how the duo presents itself and how we write about it.

## Files
- `posicionamento.md` - working name, theme and brand promise.
- `guia_visual.md` - visual direction, palette and photo treatment.
- `pesquisa_publica.md` - public web findings and what remains provisional.

## Working Principle
Identity here should stay grounded in what is actually documented:
- local repertoire
- real photos and videos when they arrive
- confirmed public bios or links

If something is not confirmed, keep it as a working note, not as final copy.
