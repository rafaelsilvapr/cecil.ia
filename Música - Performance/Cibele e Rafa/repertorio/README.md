# Repertorio

Este folder e a base unica para setlists, blocos e referencias de show.

## Arquivos Principais
- `catalogo_canonico.md` - indice unico de cancoes.
- `blocos_e_medleys.md` - sequencias, medleys e blocos prontos.
- `como_pedir_setlist.md` - formulario curto para pedidos futuros.

## Como Pensar O Repertorio
- o repertorio nao e uma lista solta, e uma biblioteca de funcao
- cada musica pode servir a mais de um contexto
- os medleys contam tanto quanto as musicas isoladas
- o show deve ser montado por clima, energia e encaixe de tom

## Regras De Uso
- quando pedir um setlist, informar duracao, perfil do publico, energia e musicas obrigatorias ou proibidas
- preferir blocos que se conectem de forma natural
- deixar claro quando a ordem e para abrir, crescer ou fechar o show
- respeitar a logica de samba, rapido, romantico, festa e rebarba

## Boa Pratica
Se uma musica aparece em mais de um lugar, isso normalmente significa funcao diferente, nao erro.
