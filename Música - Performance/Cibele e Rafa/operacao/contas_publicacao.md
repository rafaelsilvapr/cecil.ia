# Contas De Publicacao

Este arquivo e a referencia canonica das contas usadas para divulgar o trabalho da dupla.

## Como usar
- Use este cadastro quando for montar legenda, selecionar destino de publicacao ou validar qual conta deve receber cada video.
- Se um identificador interno do Make estiver diferente do `@` publico, o identificador interno do Make vence na automacao.
- Se algum dado nao estiver confirmado, marque como `a confirmar` antes de publicar.

## Regras De Operacao
- Para cada video, selecione a conta de publicacao com base no ciclo e na estrategia do dia.
- Se a estrategia for alternar por pessoa, mantenha a alternancia na planilha ou no Data Store.
- Se a estrategia for publicar como dupla, use a pagina do Facebook e avalie manualmente o Instagram colaborativo.
- Nunca invente um `@` ou um id interno de conexao.

## Pendencias
- Confirmar o page id real da pagina da dupla dentro do Make.
- Confirmar os ids internos das contas de TikTok e YouTube depois que as conexoes forem criadas.
- Confirmar o caminho de publicacao colaborativa no Instagram antes de automatizar.
